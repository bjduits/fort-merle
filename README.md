# Escape from Fort Merle

A twelve-night escape from a North Sea prison island: search the painted rooms, steal oak, rope,
canvas and pitch, build a boat in the sea cave and run on the spring tide.

Play it here: **https://bjduits.github.io/fort-merle/**

On a phone you can install it: open the link, then "Add to Home Screen" (iPhone, in Safari's share menu)
or "Install app" (Android, in Chrome's menu). After the first visit it runs without internet.

Pictures made with Gemini, narration and character voices recorded with text to speech,
and all the sound effects, ambience and music are synthesised in the browser.
